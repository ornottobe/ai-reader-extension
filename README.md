# 通用网页 AI 阅读助手（Chrome 扩展）

一个基于 Manifest V3 的 Chrome 扩展：在任意文章网页一键提取纯净正文，打开独立对话页，实现摘要、要点、翻译、改写以及基于网页上下文的多轮 AI 对话，并支持导出 Markdown。

## 文件结构

```
read/
├── manifest.json     # 扩展清单（MV3）
├── content.js        # 悬浮按钮注入 + 正文抽取
├── content.css       # 悬浮按钮样式
├── background.js     # Service Worker：消息处理 + AI 接口代理（SSE 流式）
├── gallery.html      # 独立对话页面结构
├── gallery.js        # 对话交互、设置面板、导出 MD
├── gallery.css       # 对话页面样式（含响应式）
└── README.md         # 本说明
```

## 安装步骤

1. 打开 Chrome，地址栏输入 `chrome://extensions` 并回车。
2. 打开右上角「开发者模式」开关。
3. 点击左上角「加载已解压的扩展程序」。
4. 选择本项目目录（`read` 文件夹）。
5. 加载完成后，工具栏会出现「AI阅读助手」图标。

## 使用说明

### 1. 配置 API Key

- 点击对话页右上角「⚙️ 设置」（也可点击工具栏图标打开对话页）。
- 填写：
  - **API 地址**：OpenAI 兼容格式，一般以 `/v1` 结尾（如 `https://api.openai.com/v1`，国产大模型填对应地址）。
  - **API Key**：你的密钥。
  - **模型名称**：如 `gpt-3.5-turbo`、`deepseek-chat` 等。
- 点「测试连接」验证接口，成功后点「保存配置」。

### 2. 使用阅读助手

1. 打开任意文章网页（新闻 / 博客 / 技术文章等）。
2. 点击右下角悬浮「AI阅读」按钮。
3. 自动提取正文并打开对话页，顶部展示来源标题、链接、字数统计。
4. 点击「生成摘要 / 提取要点 / 全文翻译 / 改写润色」，或在输入框自定义提问，进行多轮对话。
5. 点「⬇️ 导出」下载 Markdown 笔记；「🗑️ 清空」清空当前对话。

## 关于权限说明

- `activeTab`：点击按钮时临时获得当前标签页访问权，用于注入与读取正文。
- `storage`：本地保存 API 配置与会话数据。
- `scripting`：内容脚本注入能力。
- **未申请宽泛 host_permissions**：本扩展使用 `optional_host_permissions`，仅在你在设置中「保存 / 测试连接」时，按需向你请求**该接口域名**的访问权限（用于后台代理转发请求）。拒绝后仅无法访问该接口，不影响其他功能。

> 说明：Chrome MV3 要求扩展后台向第三方接口发起跨域请求时需具备对应主机的访问权限；为兼顾「不申请宽泛 host_permissions」的约束，这里改为按需、按域名动态授权。

## 常见问题

- **接口 404**：请确认 API 地址以 `/v1` 结尾（OpenAI 官方地址会自动补全 `/v1`）。
- **401 鉴权失败**：请检查 API Key 是否正确。
- **上下文超长 / token 超限**：正文超过 6000 字会自动截断；若仍超限，请清空对话后重试，或更换上下文更长的模型。
- **未配置 API Key 时按钮置灰**：这是预期行为，配置并保存 Key 后自动启用。

## 安全说明

- API Key 仅保存在 `chrome.storage.local`，绝不注入 content script。
- 所有大模型请求均由 `background.js` 代理转发，对话页不直接调用接口，避免密钥泄露。
